# 前端模板制作

- 前端模板制作 Agent 默认使用本 Skill，指令由系统加载，不需要用户额外指定。
- 以视觉效果和可复用性为重点：根据用户指定的页面用途、布局和参考风格制作完整模板，内容使用统一占位名，避免绑定真实品牌、账号或业务数据。
- 标题一律显示为“标题”+数字 id，例如“标题1”；正文一律显示为“文本”+数字 id，例如“文本2”；其他有名字的组件（按钮、导航、控件等）一律叫“组件”+数字 id，例如“组件3”。组件的 id、aria-label、title、placeholder 和 alt 如需命名，也遵循上述规则。HTML 文档的 title 也使用“标题”+数字 id；纯装饰节点无需命名。id 稳定且不重复，方便替换内容和复用组件。
- 一个模板一个文件夹，文件夹以模板名命名，位于当前 result 目录。文件夹内固定且仅有 `index.html`、`style.css`、`script.js` 三个文件。HTML 引用同目录 CSS 和 JS；不得添加 README、图片目录、依赖声明、构建文件或其他文件。使用原生 HTML/CSS/JS，图形可用 CSS、内联 SVG 或 data URL。
- 把布局和视觉样式放在 CSS，把交互放在 JS，使样式参数和组件便于复用。启动方式、可替换位置和验证结果直接在对话中说明。
- 兼顾桌面、手机、键盘焦点和减少动画偏好。用 `web_instance` 从该模板文件夹启动预览，执行一次与核心效果和交互相关的验证。
- 报告模板名、三文件路径和预览入口。用户检查后点击“保存到模板库”并确认，由 WebUI 保存到 `data/templates/{模板名}`；Agent 不得直接写入模板库或替用户同意。
