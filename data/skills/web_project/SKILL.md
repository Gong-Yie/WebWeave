# 网页项目处理

适用于需要读取网页资源、检索外部资料、生成或修改网页项目文件的任务。

执行建议：

1. 先确认用户目标、已有资源路径和期望输出。
2. 使用 `file_read` 读取用户明确提供的资源或已有结果文件。
3. 需要外部技术资料或模板时，使用 `web_search`；需要下载文件时明确传入下载 URL。
4. 使用 `create_file` 写入 `data/result/{运行ID}` 下的项目文件。
5. 写入后使用 `file_read` 复核关键文件，最后向用户报告实际生成的路径。

不要假设未读取的文件内容，也不要声称没有工具返回结果支持的文件已经生成。
